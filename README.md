# 🃏 Projeto Super Trunfo 
Um jogo de cartas baseado no clássico Super Trunfo, com tema "Carros Brasileiros". Desenvolvido em linguagem C, como projeto acadêmico na disciplina FUNDAMENTOS DE PROGRAMAÇÃO 2

## 🕹 Funcionalidades
- Gameplay
  - Jogar em Lan
  - Jogar Local
  - Jogar contra computador

- Vizualizar Cartas
  - Navegar entre todas as cartas
  - Pesquisar por atributos
  - Pesquisar por atributos, dentro de um intervalo

- Gerenciar Cartas
  - Inserir cartas
  - Deletar cartas
  - Alterar cartas

- Menus e Submenus

- Tratamento de erros do usuario

## 🛠️ Estrutura do Projeto

## 🚀 Como Compilar e Executar?

-  Pré-requisitos:
   - Tenha um compilador C instalado (como gcc).

- compilação:
  - make
 
- Execução:
  - make run
